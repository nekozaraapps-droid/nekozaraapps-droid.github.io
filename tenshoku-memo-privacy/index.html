転職Memo プライバシーポリシー

最終更新日：2026-11-11

要約

転職Memoは、利用者の情報を集めません。送りません。人に渡しません。
アプリに入れた記録は、すべてお使いの端末の中だけに保存されます。開発者のもとへ送られることはありません。

1. 集める情報

ありません。

転職Memoにはアカウントの登録がなく、開発者のサーバーと通信する機能もありません。
氏名、メールアドレス、電話番号、位置情報、端末の識別子、広告の識別子、使い方の統計、クラッシュの記録。どれも集めません。
解析のツールや広告の仕組みも入っていません。

2. 端末の中に保存するもの

アプリに入れた次の記録は、端末の中のアプリ専用の場所にだけ保存します。

記録使いみち
応募（会社名・経由・状態・条件のメモ）応募の一覧・件数・くらべ表
予定（面接・失業認定日・職業訓練の選考など）次の予定・通知・ウィジェット
面接シート（聞かれたこと・答え・感じたこと）面接の記録・対策の道具
定番の答え・書類の部品対策の道具
求職活動の記録回数の表示
設定（外観・通知の時刻・Face ID のオン／オフなど）表示と動きを保つため
Pro を買ったかどうかの控えPro の中身を開くため

これらが自動で端末の外へ送られることはありません（利用者が自分で送る場合は、下の「3. 端末の機能の使いみち」の「共有」を見てください）。
アプリを削除すると、これらの記録もすべて消えます。
なお、iPhone 本体のバックアップ（iCloud バックアップなど）を使っている場合は、iOS の仕組みで、そのバックアップの中に含まれることがあります。バックアップの扱いは Apple のプライバシーポリシーに従います。

3. 端末の機能の使いみち

次の機能を使うことがあります。どれも、利用者が使うと決めたときだけ動きます。

  • 通知 — 通知をオンにした予定の、前の日の決まった時刻と、面接の始まる時刻の1時間後にお知らせします。端末の中で予約するローカル通知で、通知のサーバーは使いません。通知の文は「予定があります」だけで、会社名や予定の種類は出しません（iOS の決まりで、アプリの名前とアイコンは表示されます）。
  • Face ID（またはパスコード） — その他の画面でロックをオンにしたときだけ使います。顔のデータは iOS が扱い、アプリには「確かめられたかどうか」しか届きません。
  • ウィジェット — ホーム画面のウィジェットに、次の予定（日時・会社名・種類）を出します。表示のために、端末の中でアプリとウィジェットが共有する場所に予定の文を置きます。端末の外には出ません。
  • 共有 — 対策の「書類の部品箱」で「コピー・送る」を押したときだけ、その部品の文を iOS の共有の画面に渡します。どこに送るか、送るかどうかは利用者が選びます。送った先での扱いは、そのサービスに従います。

通知と Face ID は断ることができます。断った場合も、その機能が使えないだけで、ほかの機能はそのまま使えます。

4. App内課金

Pro の購入と復元は、Apple の App Store の仕組みで行います。支払いの情報は Apple が扱い、開発者には届きません。
値段の表示、購入したかどうかの確認、購入と復元のときに、端末が App Store と通信します。この通信は Apple のプライバシーポリシーに従います。記録をつける・見るのは、通信なしでできます。
その他の「プライバシーポリシー」を押すと、このページをブラウザで開きます。「作っている他のアプリ」で「入手する」を押すと、App Store のそのアプリのページを開きます。どちらも、何かを送ることはありません。

5. ほかの人への提供

しません。集めていないので、渡したり売ったりする情報がありません。

6. このポリシーを変えるとき

このページを直し、上の最終更新日を改めます。記録の扱いが大きく変わるときは、アプリの更新情報でもお知らせします。
